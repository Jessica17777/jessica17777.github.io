# Design — 严嘉琪个人网站设计说明

## 1. 设计定位
简约、干净、有质感的个人网站。米白色背景搭配深灰文字与暖棕点缀色，体现金融领域的沉稳专业感。

## 2. 页面结构
Hero → About（含教育+校园经历） → Skills → Projects → Contact

## 3. 配色方案
| 用途 | 色值 |
|------|------|
| 背景 | #fafaf8（米白） |
| 卡片背景 | #fafaf8 / #fff |
| 主文字 | #3d3d3d（深灰） |
| 辅文字 | #8a8a8a / #aaa5a0 |
| 点缀色 | #c17a5d（暖棕） |
| 边框 | #eeeae3 / #ddd8d0 |

## 4. 字体
系统原生字体栈，干净简洁。

## 5. 响应式
桌面端多栏布局，移动端 768px 以下切换为单栏/两栏。

## 6. 关键文件
| 文件 | 职责 |
|------|------|
| index.html | 唯一的页面文件（含 HTML + CSS） |
| docs/prd.md | 需求文档 |
| docs/design.md | 设计说明 |
| docs/checklist.md | 验收清单 |
| report/final-report.md | 实验报告 |
