# PRD — 严嘉琪个人网站

## 1. 项目概述
个人品牌展示网站，定位为"金融 · 投资 · 数据分析"。用于夏令营作业验收和未来实习求职展示。

## 2. 目标访问者
- 夏令营教师/助教：检查五个区块完整性与内容真实性
- 未来实习面试官：了解专业背景、技能栈、项目经验
- 同学/同行：了解学习方向和兴趣领域

## 3. 包含内容
- Hero：姓名 + 定位 + 联系方式
- About：个人简介 + 教育背景 + 成绩亮点 + 校园经历
- Skills：金融分析 + 编程工具 + 金融数据工具
- Projects：5 个真实项目
- Contact：GitHub 链接

## 4. 不做什么
- 不加入登录、数据库、支付、后台系统
- 不收集访问者个人信息
- 不发布手机号、住址、身份证等隐私

## 5. 完成标准
- 五个内容区块齐全，内容真实
- 桌面端和移动端均可正常阅读
- PRD / Design / Checklist 三份文档存在且一致
- GitHub Pages 可公开访问
- 至少有 3 次有意义 Commit
